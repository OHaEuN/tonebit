# 3. 요구사항 정의서

> **범위:** 셀카·카메라로 12톤을 가늠하고, 인기 립을 내 피부와 취향에 맞춰 순위를 내고, 얼굴에 발라 본 뒤 구매 링크로 보내는 웹 서비스. 회원가입·앱·유료 기능은 없다.

기준일 2026-11-11. 우선순위는 P0(없으면 서비스가 아님), P1(첫 출시), P2(지표 뒤). 상태는 지금 배포본 기준.

---

## 1. 기능 요구사항

### 1.1 측정

| ID | 요구사항 | 우선순위 | 수용 기준 | 상태 |
|---|---|---|---|---|
| FR-01 | 카메라로 얼굴을 찍어 측정한다 | P0 | 권한 허용 뒤 얼굴이 잡히면 "측정 시작"이 활성화되고, 20프레임 중앙값으로 결과가 난다 | 완료 |
| FR-02 | 사진을 올려 측정한다 | P0 | JPG·PNG·HEIC(브라우저가 여는 형식) 1장 이상, 얼굴이 잡히면 결과가 난다 | 완료 |
| FR-03 | 사진을 한 번에 여러 장 올려 합친다 | P1 | 최대 5장, 고른 사진을 다 본 뒤 한 번에 판정하고 "사진 N장을 합친" 머리말과 사진별 탭이 보인다 | 완료 |
| FR-04 | 결과 뒤에도 사진을 더하거나 한 번 더 측정한다 | P1 | 남은 칸(5장)만큼 받고, 넘치면 몇 장을 뺐는지 알린다 | 완료 |
| FR-05 | 얼굴을 못 찾거나 피부색을 못 읽으면 알린다 | P0 | 문구가 뜨고 보고 있던 결과는 유지된다. 여러 장 중 일부만 실패하면 빼고 합쳤다고 알린다 | 완료 |
| FR-06 | 조명 상태를 측정 전에 알린다 | P1 | 어두움·역광·색 편향·얼굴 작음을 배지로 보여 준다 | 완료 |
| FR-07 | 치아·눈 흰자로 조명을 자동 보정한다 | P1 | 보이는 프레임·사진에서 자동 적용되고, 어떤 기준을 썼는지 측정값 자세히에 적힌다 | 완료 |
| FR-08 | 사진 속 흰색을 눌러 조명을 보정한다 | P1 | 흰 종이·흰 벽 후보를 자동으로 찾아 제안하고, 직접 누를 수도 있다. 너무 어둡거나 날아갔거나 색이 있으면 거절 문구 | 완료 |
| FR-09 | 카메라에서 흰 종이로 화이트밸런스를 고정한다 | P2 | 지원 기기에서만 카드가 보인다 | 완료 |

## 2. 비기능 요구사항

| ID | 항목 | 요구사항 | 수용 기준 | 상태 |
|---|---|---|---|---|
| NFR-01 | 개인정보 | 얼굴 이미지·프레임이 브라우저 밖으로 나가지 않는다 | CSP `connect-src 'self'`, 사진 업로드 API 없음, 이벤트에 얼굴·측정 수치 없음 | 완료 |
| NFR-02 | 보안 | 외부 스크립트는 분석 도구 하나 | Umami만, 쿠키 없음 | 완료 |
| NFR-03 | 성능 | 랜딩은 얼굴 인식 모델을 내려받지 않는다 | tasks-vision(약 10MB)은 /try에서 lazy import, 모델·wasm은 immutable 캐시 | 완료 |
| NFR-04 | 성능 | 카메라 발라 보기가 끊기지 않는다 | rAF 루프, 10프레임마다 조명 체크 | 완료 |
| NFR-05 | 호환 | iOS Safari·안드로이드 Chrome·데스크톱 Chrome | 카메라 거부·미지원이면 업로드로 안내 | 완료 |
| NFR-06 | 접근성 | 키보드와 스크린리더로 흐름을 끝낼 수 있다 | 진행 막대 aria, 탭 역할, 라이브 영역, 보이는 포커스 | 확인 필요(검사 도구 미실행, 손으로만 봄) |
| NFR-07 | 문구 | 완전한 문장, 용어 없음, 글자 크기 유지 | 폰 390px·데스크톱 1280px 캡처로 감사 | 완료 |
| NFR-08 | 비용 | 월 0원 | 무료 등급만, 값이 없으면 해당 기능만 꺼짐 | 완료 |
| NFR-09 | 품질 | 단위·E2E·통합·도커 네 작업이 CI에서 돈다 | master 머지 전 전부 통과 | 완료 |
| NFR-10 | 운영 | 배포는 master 머지로 자동 | Vercel 자동 배포, DB 마이그레이션 워크플로 | 완료 |
| NFR-11 | 데이터 | 서버 DB에는 숫자와 글만 | feedback·result_reactions·advisor_ratings·advisor_usage | 완료 |
| NFR-12 | 공개 | 연락처를 페이지에 싣지 않는다 | 문의는 GitHub 이슈 | 완료 |

## 3. 만들지 않는 것

- 회원가입·로그인, 결과 서버 저장(결과는 링크로 공유)
- 네이티브 앱, 푸시
- 피부 질환·의료 판단
- 쇼핑몰 크롤링, 실시간 가격·재고
- 광고, 유료 진단
- 영어 등 다국어(지표 뒤 판단)
