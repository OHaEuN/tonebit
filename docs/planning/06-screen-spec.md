# 6. 화면설계서

> **원칙:** 한 화면에 질문(제목) 하나와 주 행동 하나. 위에 진행 막대, 아래에 주 행동, 가운데에 그 화면의 한 가지 일. 모든 문구는 완전한 문장이고 용어가 없다.

기준일 2026-11-11. 화면 ID는 S-번호. 문구는 배포본 그대로다. 캡처는 저장소 `docs/`와 블로그 글 31에 있다.

---

## S-00 공통 요소

| 영역 | 요소 | 동작·규칙 |
|---|---|---|
| 상단 띠 | "사진은 기기 밖으로 나가지 않아요" | 모든 페이지. 데스크톱은 영문도 같이 |
| 헤더 | 톤빛 / 12 TONES / COLOR TEST | 로고는 랜딩, 12 TONES는 랜딩의 12톤 섹션, COLOR TEST는 /try |
| 사진 무대 | 캔버스, 처음부터, 크게 보기 | 결과 뒤에만. 꾹 누르면(220ms) 바르기 전, 짧게 누르면 크게 보기 모달. 처음부터는 모든 상태를 지운다 |
| 진행 막대 | 5칸 | 본 흐름에서만. 곁가지는 없음 |
| 톤 알약 | 예: "봄 웜 브라이트" | 2단계부터 오른쪽 위에. 지금 보고 있는 결과의 톤 |
| 뒤로 | 왼쪽 위 화살표 | 브라우저 뒤로와 같다 |
| 푸터 | 정확도 / 개인정보처리방침 / GitHub | 모든 페이지 |
| 크게 보기 모달 | 사진 확대, 빠른 발라 보기 | 얼굴 기준으로 확대. 결과 뒤에만 |

## S-01 랜딩 (/)

목적: 10초 안에 무엇을 하는 서비스인지 알고 테스트로 들어가게 한다. 서버 컴포넌트라 클라이언트 JS가 거의 없다.

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 히어로 | 제목, 부제, 주 행동 | 부제 "셀카 한 장으로 내 톤을 가늠하고, 어울리는 립을 얼굴에 발라 봐요." 주 행동은 /try |
| 12톤 | 12개 톤 카드 | 각 /r/[tone]으로. 시즌 색 점과 이름 |
| 결과 예시 | 여름 쿨 라이트 예시 | 실제 팔레트와 제품 3개를 그대로 보여 준다 |
| 이렇게 해요 | 3단계 | "카메라를 켜거나 사진을 올려요 / 자연광 아래 정면이 가장 정확해요", "볼과 이마의 색을 읽어요 / 웜·쿨과 12가지 시즌 중 가능성이 높은 톤을 골라요", "둘 중 고르고, 내 립을 받아요 / 내 얼굴에 바른 두 립 중 나은 쪽을 고르면 내 순위가 나와요" |
| 개인정보 | 한 문단 | 얼굴 인식과 색 분석이 브라우저 안에서 끝난다는 한 문장 |

## S-02 테스트 시작 (/try, stage=setup)

목적: 카메라 또는 사진으로 시작한다. 모델을 내려받는 동안 기다리게 한다.

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 안내 | 소개 한 줄 | "셀카 한 장이면 돼요." |
| 모델 상태 | 진행률 → "준비됐어요" | 약 10MB 모델. 실패하면 다시 시도 버튼 |
| 주 행동 | 데스크톱: 카메라로 시작(주) + 사진 올리기(보조). 모바일: 사진으로 시작하기(주) | 모바일은 이 버튼 하나가 카메라·앨범 선택창을 띄운다. 여러 장 선택 가능 |
| 사진 팁 | 4개 | 자연광 아래 정면("창가에서, 앞머리는 넘기고"), 이가 보이게 웃기("치아를 기준으로 조명을 맞춰요"), 흰 종이를 얼굴 옆에("같이 찍으면 조명을 더 정확히 맞춰요"), 여러 장이면 더 정확("다른 곳에서 찍은 사진을 더하면 더 정확해요. 최대 5장") |
| 예외 | 카메라 거부 | "카메라 권한이 거부됐어요" + 사진 올리기가 주 행동으로 |

## S-03 카메라 라이브와 측정 중 (stage=live, measuring)

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 무대 | 거울 모드 영상 | 좌우 반전 |
| 조명 배지 | "얼굴을 찾는 중…" → "조명 좋아요" 또는 문제 배지 | 10프레임마다 갱신. 어두움·역광·색 편향·얼굴 작음 |
| 주 행동 | "측정 시작" | 얼굴이 잡힐 때까지 비활성 |
| 팁 | 한 줄 | "이가 보이게 살짝 웃거나 눈을 크게 뜨면 치아·눈 흰자를 기준으로 조명을 더 정확히 되돌려요." |
| 흰 종이 고정 | 카드(지원 기기만) | 흰 종이를 대고 고정 → 화이트밸런스 잠금 |
| 측정 중 | "가만히 있어 주세요… N%" + 막대 | 20프레임 |

## S-04 사진 분석 중 (stage=measuring, source=image)

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 진행 | "사진을 보는 중… N%" + 막대 | 장수 기준 진행률. 다 본 뒤 한 번에 판정 |
| 조명 배지 | 마지막으로 본 사진 기준 | |
| 예외 | 전부 실패 | "얼굴을 찾지 못했어요. 정면이 잘 보이는 사진으로 다시 올려 주세요" 또는 "피부색을 읽지 못했어요. 더 밝은 사진으로 시도해 주세요". 일부 실패는 "N장 중 M장은 얼굴이나 피부를 찾지 못해 빼고 합쳤어요". 초과는 "한 번에 최대 5장까지 합칠 수 있어서 N장은 뺐어요" |

## S-05 내 톤 (1/5)

목적: 결과를 한눈에 보여 주고 "어울리는 립 찾기"로 보낸다.

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 머리말 | "내 퍼스널 컬러" | 여러 장이면 "사진 N장을 합친 내 퍼스널 컬러", 한 장을 보는 중이면 "사진 한 장으로 본 내 퍼스널 컬러". 카메라는 "N번 측정을 합친" |
| 제목 | 색 점 + 톤 이름 | 예: 봄 웜 브라이트 |
| 본문 | 웜·쿨 한 문장 | "웜톤 피부예요." / "쿨톤 피부예요." / 뉴트럴: "웜과 쿨의 중간인 뉴트럴이에요. 노란기가 조금 더 있어 웜 쪽으로 봤어요." |
| 사진별 탭 | 합친 결과 + 사진 N | 두 장 이상일 때만. 누르면 무대 사진·제목·알약이 그 사진 결과로. 한 장 보는 중 "이 사진 한 장만 본 결과예요. 합친 결과가 더 믿을 만해요." 갈리면 "사진마다 결과가 갈려서 가운데 값으로 판정했어요. 사진을 누르면 한 장씩 볼 수 있어요." |
| 추천 색 띠 | 립 색 8개 | 시즌 팔레트를 세부 타입 순으로 |
| 가능성 | "가능성 N% · 다음 후보 X N%" | |
| 설명 | 톤 특징 한 문단 | 예: "노란기 도는 피부에 눈동자·머리의 대비가 또렷한 타입. 선명하고 따뜻한 색이 생기를 주고, 흐린 색은 밋밋해 보여요." |
| 경계 안내 | 확신도 낮음일 때 | "두 톤의 경계예요. 사진을 더하면 더 또렷해져요." 사진마다 갈린 경우엔 탭 안내로 대신 |
| 반응 | "이 결과, 내 생각과 비슷해요?" 비슷해요 / 잘 모르겠어요 / 달라요 | 측정을 끝낸 모두에게 한 번. "달라요"는 정확도 높이기의 전문가 진단 입력으로 이어 줌. 셀프 리뷰 뒤 정확도 높이기에서 옮김 |
| 조명 안내 | 문제가 있고 완전 보정이 아닐 때 | "{조건} 조건이라 결과가 평소와 다를 수 있어요. 사진을 더하면 정확해져요." |
| 주 행동 | "어울리는 립 찾기" | → 느낌 |
| 보조 | "정확도 높이기", "결과 카드와 추천 보기" | |
| 면책 | 구분선 아래 | "재미로 보는 테스트예요. 조명과 화장에 따라 결과가 달라질 수 있어요." 이 화면에만 |

## S-06 느낌 (2/5), S-07 질감 (3/5)

| 화면 | 제목 | 본문 | 선택지(제목 / 설명) | 규칙 |
|---|---|---|---|---|
| 느낌 | 어떤 느낌의 립을 원해요? | 평소 손이 가는 쪽이면 돼요. | 자연스럽고 세련된 / 내 입술색 같은 차분한 색 · 화사하고 생기 있는 / 밝고 맑은 핑크·코랄 · 또렷하고 매혹적인 / 진하고 붉은 레드·베리 | 누르면 바로 다음 |
| 질감 | 어떤 질감이 좋아요? | 좋아하는 쪽을 골라 주세요. | 촉촉하게 반짝이는 / 글로스·시럽·물광 틴트 · 보송하게 번지는 / 블러·벨벳·매트 · 상관없어요 / 질감은 안 따져요 | 누르면 바로 둘 중 고르기. taste-set 이벤트 |

## S-08 둘 중 고르기 (4/5)

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 제목·본문 | "어느 쪽이 더 마음에 들어요?" / "내 얼굴에 바른 모습이에요. 7번 고르면 내 눈에 맞춰 순위가 바뀌어요." | |
| 진행 | "8강 1/4" 같은 라벨 + 막대 | 8강 4, 4강 2, 결승 1 |
| 카드 A·B | 내 얼굴에 그 립을 바른 모습, 제품 이름 | 누르면 다음 대진. 이긴·진 립의 점수 축을 기록해 가중치 학습 |
| 보조 | "건너뛰기" | pick-skip, 기본 가중치로 내 립으로 |
| 예외 | 얼굴 사진 없음 | 제목 "얼굴 사진이 없어요", 본문 "측정을 다시 하면 둘 중 고르기를 할 수 있어요.", 건너뛰기만 |

## S-09 내 립 (5/5)

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 제목·본문 | "내 얼굴에 어울리는 립" / 고르기를 했으면 "내 피부와 방금 고른 취향에 맞춘 순위예요." 아니면 "내 피부에 맞춘 순위예요." | |
| 순위 목록 | 순위, 브랜드·이름·색 이름, 색 칩, 점수, ▲▼ | ▲▼는 "고르기 전 순위와의 차이예요." 고르기를 했을 때만 |
| 왜 이 점수예요? | 펼치면 아홉 항목 막대와 한 줄씩 | 밝기, 언더톤, 붉은기, 채도, 조화, 시즌 맞춤, 유행, 인상, 질감 |
| 구매 | 각 행에 쿠팡 링크 | product-click(id, from=match, rank) |
| 꼴찌 비교 | "가장 안 어울리는 립과 나란히 보기" | "인기 제품 N개 중 꼴찌와 1등이에요." 두 얼굴 나란히, 구매 링크(from=faceoff) |
| 고지 | "인기 순위는 2026년 9월 기준이에요. 제품 링크는 쿠팡 파트너스 활동의 일환으로…" | 기준 시점은 상수. 셀프 리뷰 뒤 추가 |
| 주 행동 | "1등 립 얼굴에 발라 보기" | → 발라 보기 |
| 보조 | "AI에게 더 물어보기"(켜져 있을 때), "결과 카드와 추천 보기" | |

## S-10 발라 보기 (step=tryon)

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 무대 | 사진 위에 고정 | 모바일은 스크롤하면 작게 접힘. 꾹 누르면 바르기 전 |
| 바를 곳 | 탭: 립 / 블러셔 | |
| 팔레트 | 색 칩 목록 "인기 제품, 어울리는 순" | 누르면 바로 발색. 제품 칩에 구매 링크(from=tryon) |
| 시즌 전환 | "다른 시즌 색과 비교해 보기" | 팔레트 시즌만 바꾼다. 판정은 그대로 |
| 내 제품 | 내 제품 색 재기 | 흰 종이에 바른 립을 찍고 종이와 칠한 곳을 차례로 누름 → 반사율로 환산 → 내 제품 칩과 순위에 들어감 |
| 조절 | 진하기, 바르는 방법(립: 풀 등, 블러셔: 광대 등) | |
| 고지 | "제품 링크는 쿠팡 파트너스 활동의 일환으로…" | 셀프 리뷰 뒤 추가 |
| 돌아가기 | "결과로 돌아가기" | → 내 립 |

## S-11 정확도 높이기 (step=tune)

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 제목·본문 | "정확도 높이기" / "사진을 더하거나 흰 종이를 찍으면 더 정확해져요." | |
| 장수 | "사진 1장으로 본 결과예요." / "N장을 합친 결과예요." | 카메라는 "측정 1번" / "N번 측정" |
| 사진별 탭 | S-05와 같은 컴포넌트 | |
| 더하기 | "사진 추가해서 합치기 (n/3)" 또는 "한 번 더 측정해서 합치기 (n/3)" | 5장이 차면 숨김 |
| 흰색 기준으로 더 정확하게 | 접이식 | 힌트 "사진 속 흰 종이나 흰 벽을 눌러요". 조명 색이 섞이면 펼쳐진 채 힌트 "조명 색이 섞인 사진이라 맞추는 걸 권해요". 안에 "찾은 흰색으로 맞추기" / "직접 누르기" / "사진에서 흰색 누르기" / 맞춘 뒤 "다시 맞추기". 거절 문구 세 가지 |
| 왜 이렇게 나왔나요 | 접이식, 문장 목록 | 색상각·밝기·채도·보정 기준 |
| 전문가에게 퍼스널 컬러 진단을 받아 봤나요? | 접이식 폼 | 힌트 "알려 주시면 기준을 다듬는 데 써요". 동의 뒤 톤 선택 → POST /api/feedback |
| 다시 측정 | 카메라일 때만 | |
| 측정값 자세히 | 접이식 | Lab, ITA, 깊이, 채도, 보정 기준. 이 화면에만 |

## S-12 AI에게 물어보기 (step=ask)

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 제목·본문 | "AI에게 물어보기" / "내 톤에 맞는 립이나 피할 색을 물어보세요. 사진은 보내지 않아요." | |
| 입력 | 질문 한 줄 | 진단 숫자와 질문만 전송 |
| 진행 | "립을 찾는 중…" 같은 진행 이벤트 | NDJSON 스트리밍 |
| 답 | 글 + 제품 카드(구매 링크 from=advisor) + "발라 보기" | 발라 보기는 검색에 나온 제품만. 누르면 크게 보기 모달에 바름 |
| 평가 | 도움이 됐어요 / 아쉬워요 | 답마다 |
